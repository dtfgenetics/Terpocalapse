# Terpocalypse — Style Guide

## Core Visual Direction

Terpocalypse should look like a gritty 1990s-inspired retro FPS filtered through cannabis grow-room horror comedy.

The game should feel:

- fast
- grimy
- neon-toxic
- industrial
- funny but still intense
- pixel-heavy
- readable during combat

## Tone Words

- contaminated
- bunker-grown
- resin-soaked
- moldy
- high-energy
- arcade horror
- grow-lab chaos
- secret facility
- THC community parody

## Color Palette Direction

Use these as art-direction targets, not strict final hex rules yet.

### Primary Colors

- Toxic grow green
- Deep bunker black
- Industrial gray
- Amber resin gold
- Mold white
- Warning orange
- Purple keycard / genetics accent

### Avoid

- overly cute pastel colors
- clean dispensary-only branding
- copied Doom red/orange UI treatment
- hard-to-read dark-on-dark sprites

## Environment Style

The world should feel like a cultivation facility that became a biohazard maze.

Common motifs:

- mylar walls
- grow lights
- nutrient tanks
- warning signs
- concrete floors
- pipes and vents
- sticky resin leaks
- mold patches
- pest infestation marks
- seed vault security hardware

## Enemy Style

Enemies should be gross, readable, and funny in concept while still threatening in-game.

Rules:

- clear silhouette first
- strong color identity
- avoid tiny detail that disappears in motion
- each enemy should have a visual clue for its behavior
- enemies should not resemble commercial shooter monsters

## Weapon Style

Weapons should feel like improvised grow-room combat tools.

Rules:

- exaggerated shapes
- readable muzzle area
- distinct first-person silhouette
- funny names, serious function
- avoid copying classic shooter weapon silhouettes too closely

## UI Style

The UI should be chunky and functional.

HUD priorities:

1. health
2. armor
3. ammo
4. keys
5. weapon slot
6. enemy/secret counters if space allows

The HUD should use cannabis-themed framing without becoming cluttered.

## Branding Rules

- Use **Terpocalypse** as the public game title.
- Use **Grow Room From Hell** as the subtitle.
- THC / Teaching Healthy Cultivation branding can appear on title screens, menus, loading screens, and credits.
- Keep in-game HUD branding subtle.
- Do not use copyrighted game logos, game fonts, or mimicked title treatments.

## Humor Rules

The humor should come from worldbuilding, names, and exaggerated grow problems.

Good humor examples:

- mutated pests
- angry nutrient tanks
- compliance drones
- cure jar health pickups
- seed vault objectives

Avoid:

- cheap copycat jokes
- real drug-use instruction
- sales language
- copyrighted parody that is too close to one specific game

## Asset Export Guidelines

- Use transparent PNG for sprites, pickups, UI pieces, and weapons.
- Use tileable PNG/WebP for textures.
- Keep source files separate from game-ready exports when possible.
- Add version numbers to drafts.
- Keep approved exports clean and easy to replace.
