# No Doom / Commercial Shooter IP Rules

Terpocalypse is an original cannabis-themed retro FPS. It can be inspired by broad retro shooter conventions, but it must not copy protected assets or identity from Doom or any other commercial game.

## Forbidden

Do not use:

- Doom sprites
- Doom monster names
- Doom monster designs
- Doom weapon sprites
- Doom weapon names
- Doom maps
- Doom WAD files
- Doom music
- Doom sound effects
- Doom logo
- Doom title treatment
- Doom UI/status bar graphics
- copied Doom fonts or near-identical font treatments
- commercial shooter textures
- commercial shooter sound packs without clear license
- commercial game screenshots as textures or references for direct tracing

## Allowed

The project may use broad genre conventions:

- fast FPS movement
- keycards
- secret doors
- enemy rooms
- pickups
- pixel sprites
- retro HUD
- maze-like maps
- boss fights
- level exits

These are general gameplay concepts, not owned by one game.

## Naming Rules

Use original names:

- Terpocalypse
- Grow Room From Hell
- Spider Mite Swarm
- Powdery Mildew Ghoul
- Nute Burn Imp
- pH Blaster
- Neem Cannon
- Cure Jar Health
- Kief Armor

Avoid names that sound too close to copyrighted enemies, weapons, locations, or game titles.

## Asset Source Rules

Every asset must be one of the following:

1. Created originally for this project.
2. Public domain / CC0 with source recorded.
3. Open-source / permissively licensed with attribution kept.
4. Generated specifically for this project and checked for originality.
5. Purchased/licensed asset with license stored in docs or asset metadata.

## Code Source Rules

If external open-source code is used:

- record the source repository
- record the license
- keep attribution notices
- do not mix incompatible licenses blindly
- document what was copied, adapted, or only referenced

## Red Flag Check

Before committing assets, ask:

- Does this look like a Doom sprite with cannabis elements added?
- Does this use a recognizable commercial game monster silhouette?
- Does the logo mimic a protected game logo too closely?
- Did this come from a game WAD, asset rip, or fan sprite pack?
- Is the sound/music from a copyrighted game?

If the answer is yes or uncertain, do not use it.
