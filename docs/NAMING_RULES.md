# Terpocalypse Naming Rules

All game text should feel like an original cannabis grow-room game.

Use terms from cultivation, pests, mold, nutrients, cure rooms, resin, seed storage, kief, terpenes, trichomes, clones, flower rooms, and grow labs.

Preferred examples:

- Spider Mite Swarm
- Powdery Mildew Ghoul
- Nute Burn Sprayer
- Bud Rot Brute
- Root Rot Crawler
- Cure Jar Health
- Kief Armor
- Grow Light Overdrive
- Green Keycard
- Seed Bank Siege
- Rosin Reactor

Avoid generic fantasy wording when a grow-room term works better.
