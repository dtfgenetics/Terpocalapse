## Asset Licensing Rule

Every committed asset must be one of the following:

1. Original asset created for Terpocalypse.
2. Public domain / CC0 asset with source recorded.
3. Open-source or permissively licensed asset with attribution and license text preserved.
4. Paid/commercial asset with license proof retained outside the repo or documented here.
5. Generated specifically for this project and reviewed for originality.

## Code Licensing Rule

Before importing external code, document:

- source repository
- license
- files copied or adapted
- attribution required
- compatibility notes
