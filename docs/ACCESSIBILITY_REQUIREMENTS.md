# Terpocalypse Accessibility Requirements

The game should be playable and understandable for more players, including players with visual, motor, hearing, or attention-related needs.

## Required Settings

- mouse sensitivity
- volume controls
- mute option
- high contrast HUD
- readable text size
- toggle item labels
- toggle screen shake before public release
- toggle flashing effects before public release
- clear controls screen
- pause screen with restart and resume

## Visual Clarity

- do not rely on color alone for keycards or doors
- use text labels for Green, Purple, and Gold access
- keep health, armor, ammo, key, and objective text readable
- avoid tiny critical UI text
- keep enemy feedback readable against dark rooms

## Audio Accessibility

- all important audio cues should have visual feedback
- pickup, locked door, low health, objective update, and mission complete must show on screen
- subtitles or text logs should support story and facility voice lines

## Motor Accessibility

- avoid requiring rapid repeated clicking for basic play
- support keyboard movement clearly
- include pause and restart controls
- support adjustable mouse sensitivity

## Content Safety

- story stays cultivation-themed, not consumption-focused
- humor should not block gameplay clarity
- no copyrighted shooter assets or copied commercial names

## V2 Implementation Targets

- settings schema should include contrast, labels, motion, volume, and sensitivity
- renderer should show mission messages, keycard state, and objective feedback
- story system should provide readable intro, mission briefing, lore notes, and ending text
