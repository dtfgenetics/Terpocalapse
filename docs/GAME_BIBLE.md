# Terpocalypse: Grow Room From Hell — Game Bible

## One-Line Pitch

A fast, original cannabis-themed retro browser FPS where the player fights mutated grow-room threats through a contaminated underground cultivation facility.

## Project Identity

- **Game title:** Terpocalypse
- **Subtitle:** Grow Room From Hell
- **Genre:** Retro FPS / boomer-shooter-inspired browser game
- **Format:** Web-first game for the THC / DTF game hub
- **Tone:** Horror-comedy, intense, gritty, cannabis parody, not childish
- **Target feel:** Fast movement, chunky pixel art, secret rooms, keycards, enemy waves, heavy atmosphere

## Legal / IP Position

This is an original parody shooter inspired by retro FPS genre conventions. It must not use any copyrighted commercial shooter assets, names, sprites, levels, sounds, music, logos, UI treatments, or WAD data.

See `NO_DOOM_IP_RULES.md` before adding assets or code.

## Story Setup

A hidden cultivation research bunker has gone bad. Experimental genetics, contaminated nutrients, pests, mold, and unstable grow-room machinery have turned the facility into a hostile biohazard maze.

The player is the last grower still standing. Their job is to fight through the facility, secure the seed vault, stop the contamination, and survive the Grow Room From Hell.

## Player Fantasy

The player should feel like a retro action hero trapped inside a cursed cannabis facility:

- quick movement
- fast strafing
- aggressive combat
- weird enemies
- secret areas
- exaggerated weapons
- grow-room horror comedy

## Starter Enemies

### Spider Mite Swarm

- Role: fast weak swarm enemy
- Behavior: rushes player, low health, dangerous in groups
- Visual: crawling red/amber mite mass with twitchy legs

### Powdery Mildew Ghoul

- Role: slow medium enemy
- Behavior: shambles forward, close-range spore attack
- Visual: infected grower body covered in pale mold dust

### Nute Burn Imp

- Role: ranged enemy
- Behavior: throws toxic nutrient projectiles
- Visual: scorched mutant with orange chemical glow

## Progression Rules

- Players collect keycards to unlock colored doors.
- Secrets reward health, armor, ammo, or bonus collectibles.
- Levels should be maze-like but readable.
- Combat rooms should open up after pickups or switches.
- The first level should teach movement, shooting, pickups, doors, and exits.

## Design Priorities

1. Playable first.
2. Original assets only.
3. Simple systems that can expand.
4. Browser performance matters.
5. THC/DTF identity should be present but not visually cluttered.
6. The game should feel like a real retro shooter, not only a joke.

## What This Game Is Not

- Not a Doom clone.
- Not a reskin using copyrighted sprites.
- Not a realistic cultivation simulator.
- Not a dispensary sales tool.
- Not a cannabis consumption instruction game.
