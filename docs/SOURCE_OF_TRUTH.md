# Terpocalypse: Grow Room From Hell — Source of Truth

`dtfgenetics/Terpocalapse` is the canonical preproduction/code repository for Terpocalypse. Its current status is **prototype / asset-first vertical-slice planning**, not a production release.

Google Drive `04 Games/Terpocalapse` is canonical for approved human-readable design masters, artwork/source assets, playtest evidence, proofs, and release packages.

## Current target

The first playable target is Level 01 — The Veg Lab. Until that vertical slice is implemented and verified, repository planning documents and asset specifications are authoritative for scope, but the project must not be represented as production-ready.

## IP rule

The project is an original retro browser FPS. Do not use Doom names, logos, sprites, maps, music, sound effects, WAD data, commercial shooter assets, or copied interface/font treatments.

## Release

A future release requires a playable browser build, no release-blocking console errors, original/approved assets, controls/HUD/weapons/enemies/pickups/doors/win-condition verification, licensing review, and an approved Drive release package.
