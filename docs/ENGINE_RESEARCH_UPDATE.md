# Engine Research Update

## Current decision

Keep the current static browser prototype as the immediate foundation. It already fits the website goal because it is plain HTML, CSS, and JavaScript.

## Build path

1. Improve the current prototype until the core loop feels good.
2. Replace placeholder visuals with original Terpocalypse assets.
3. Add sound hooks, settings, run stats, and game hub events.
4. Evaluate a larger engine migration only after the first level is fun.

## Options

### Current prototype

Use now because it is website-ready, simple to host, and already contains movement, weapons, enemies, pickups, key door logic, special ability, and win state.

### doom-lite

Use later as a retro browser FPS reference or possible import candidate after license and asset audit.

### Three.js

Use later if we need a stronger browser 3D version with better scene rendering, sprites, particles, and post-processing.

### Babylon.js

Use later if we need a larger browser 3D engine with more built-in tooling.

## Recommendation

Do not switch engines until the current prototype is fun and the first level is proven.
