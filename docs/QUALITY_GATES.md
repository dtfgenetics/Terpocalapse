# Terpocalypse Quality Gates

These are the checkpoints for turning the prototype into a quality browser game.

## Gate 1: Page Loads

- Game page opens in a desktop browser.
- Start button works.
- Canvas fills the page.
- No console errors appear on page load.

## Gate 2: Core Play Loop

- Movement works.
- Turning works.
- Player can use all starter gear.
- Pickups work.
- Enemies can be cleared.
- Green keycard opens the green door.
- Exit room completes the level.

## Gate 3: Feel and Clarity

- Each starter item feels different.
- Feedback is clear when the player interacts with enemies, doors, pickups, and exits.
- HUD is readable.
- Objective is easy to understand.
- First level teaches the player without confusion.

## Gate 4: Art Replacement

- Placeholder visuals are replaced with original Terpocalypse assets.
- Asset manifest is updated.
- Missing assets fall back safely.
- No copied commercial game assets are present.

## Gate 5: Website Ready

- All paths are relative.
- Static hosting works.
- No backend is required for the first build.
- No private keys or tokens are committed.
- Route is ready for internal testing.

## Gate 6: Release Candidate

- README is accurate.
- QA checklist is current.
- Deployment plan is current.
- GitHub issues match remaining work.
- The level can be completed consistently.
