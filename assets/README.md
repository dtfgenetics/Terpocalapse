# Terpocalypse Assets

This folder contains original game-ready and source-tracked assets for Terpocalypse.

## Rules

- Do not commit Doom assets or copied commercial shooter assets.
- Keep placeholders clearly named.
- Use lowercase hyphenated filenames.
- Use transparent PNG for sprites, UI, pickups, weapons, and effects.
- Use tileable PNG/WebP for wall, floor, ceiling, and decal textures.
- Record external asset sources in `docs/LICENSING_NOTES.md` before use.

## Folder Map

```text
branding/              logos, badges, title identity
ui/                    HUD, menus, icons, crosshairs
textures/walls/        wall textures
textures/floors/       floor textures
textures/ceilings/     ceiling textures
textures/decals/       signs, labels, warning graphics
props/                 environment props
pickups/               health, armor, ammo, keys
weapons/first_person/  first-person weapon sprites
weapons/pickups/       weapon pickup sprites
weapons/projectiles/   projectiles and impacts
weapons/icons/         weapon HUD icons
enemies/               enemy concepts and sprites
effects/               muzzle flashes, smoke, splats, explosions
audio/music/           music tracks or placeholders
audio/sfx/             sound effects
story/                 story cards, terminals, intro panels
```
